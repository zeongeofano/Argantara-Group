# Argantara Group Landing Page

Landing page perusahaan Argantara Group yang dibuat menggunakan HTML, Tailwind CDN, dan JavaScript untuk efek interaktif sederhana.

## Cara menjalankan

Buka file `index.html` langsung di browser, atau jalankan server lokal:

```bash
python -m http.server 8000
```

Lalu buka:

```text
http://localhost:8000
```

## Struktur

- `index.html` — file utama landing page
- `situs_resmi_argantara_group.html` — salinan file utama sesuai nama yang Anda minta

## Catatan

Form kontak saat ini bersifat demo UI dan menampilkan notifikasi sukses di halaman, bukan mengirim email secara nyata.

Untuk pengiriman real, kita bisa menambahkan integrasi ke:
- FormSubmit.co
- WhatsApp API
- Email backend
- Google Sheets / Apps Script
